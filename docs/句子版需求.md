# EType 句子版需求讨论

基线：`7474765`，提交名称“单词版”。开发分支：`codex/sentence-mode`。

## 已确认的需求

- 2026-10-05，用户要求下载包和安装后的总占用都小；翻译与朗读转为在线方案，翻译源须免费。这替代此前默认内置本地翻译、语音模型的交付方向；当前 0.2.0 完整离线包暂不发布。
- 在线精简版的服务候选、体积目标与待验证事项见 `在线精简版方案.md`。具体服务方案的建议与用户明确确认的产品目标须区分。
- 保留英文单词输入及中文释义候选的已有功能。
- 2026-10-04，用户确认将单词和句子整合在同一个系统输入法入口，使用 Ctrl+Shift+空格切换；候选窗显示当前模式。
- 2026-10-04，用户确认句子模式 Enter 选择中文、Ctrl+Enter 输出英文；未生成候选时 Enter 发起翻译，候选出现后再次 Enter 确认当前中文。等待期间重复 Enter 不提交英文、不重复请求。
- 下一阶段支持输入完整英文句子，再选择对应中文表达。
- 用户反馈现有单词语音生硬，需要改善听感。
- 为句子增加语音功能。
- 默认口音沿用美式。
- 2026-10-04，用户明确允许联网；句子翻译和语音方案可以评估在线服务。
- 2026-10-04，用户明确要求：今后只有用户明确提出需要时，才生成 EXE 安装包或完整 EXE 交付文件；平时继续源码、预览与必要测试。
- 2026-10-04，用户同意先验证免费本地路线：Kokoro 语音与本地句子模型，先测试实际听感、速度和准确率，再决定服务方案。
- 2026-10-04，用户试听后认可当前音色，并要求继续开发；保留 Kokoro 美式音色，接入原生输入法。
- 2026-10-04，用户同意下一步先检查句子翻译质量并完善句子编辑、长译文查看、重试和播放状态；本轮继续使用开发版验证。

## 当前建议，尚待整体定稿

- 单词模式保留空格选词；句子模式空格用于分隔英文单词，完整输入后主动触发翻译。
- 中文候选根据上下文生成不同自然表达，准确优先，不强行凑候选数量。
- 发音以英文原文为主，单词和句子使用一致音色，提供正常速度、慢速、重播和停止。
- 保留手动播放；句子翻译失败或语音不可用时，保留原始英文，允许重试。
- 在线语音可缓存到本地，按文本、音色、口音和速度区分；提供清除缓存入口。
- 原离线版的单词查词与纠错使用本地词库；2026-10-05 在线分支改为在线分片词库，具体行为见 `在线精简版方案.md`。

## 保留的 0.2.0 离线版本行为

- Ctrl+Shift+空格切换单词与句子模式，也可点击候选窗左上角模式标签或在设置中选择。
- 句子模式：空格、数字、英文标点属于原句；Enter 请求翻译或确认当前中文；候选出现后也支持 1–3、方向键和空格选择中文；Ctrl+Enter 始终输出英文原句，等待期间输出英文会使旧译文失效；Esc 取消。
- 句子原文支持光标移动、选中替换和逐词编辑；上下键选候选，左右键编辑原文。长译文可用 F2 展开及滚动查看，提供重试入口和跨进程播放状态。
- 翻译使用本地 Qwen3-4B，通常返回 1–3 个候选，并复核语义；不强行补满数量，模型仍可能翻译错误。
- 每次最多 500 个 ASCII 英文字符；网络接收超时 60 秒，本机连接超时 1 秒；输入过程中修改原句、取消或切换焦点会丢弃旧译文。
- 已认可的美式语音使用本地 Kokoro：默认 Heart 女声，可选 Michael 男声，正常速度或 0.8 倍慢速，支持重播与停止。英式仍使用用户安装的 Windows 英式语音，明确标注来源。
- 本地 worker 独立运行，TSF 宿主线程只处理输入和已完成结果；发音由独立子进程播放，按软件音量缩放样本，不改系统音量。
- 开发环境可按脚本手动启动服务；用户明确要求的 0.2.0 独立安装包内置模型与运行环境，首次翻译或自然语音自动启动隐藏的本地服务，无需另装 Python。没有安装 Windows 系统服务或购买 API。
- 这些快捷键与长度是开发默认值，未冒充用户逐项确认；后续可以整体调整。

已接入开发版 TSF DLL 和原生试用窗口，并在用户要求安装后安装开发试用版本。系统旧宿主仍复用旧 DLL 的问题及新增「EType 单词与句子」系统入口，见 `句子模式安装修复.md`。验证边界见 `本地AI验证.md` 与 `原生句子开发版.md`。
