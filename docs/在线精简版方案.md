# 在线精简版方案

## 用户已确认的目标（2026-10-05）

- 下载包与安装后的总占用都要小。
- 单词、句子翻译与朗读采用在线方案，翻译源选择免费服务。
- 保留既有单词多义候选、完整拼写与纠错、句子编辑、模式切换及确认键行为。
- 原 0.2.0 完整离线包的 GitHub Release 保持草稿，上传任务已停止。
- 按项目约定，先开发与测试；不因为讨论在线方案就生成新 EXE。

## 在线分支已接入的服务（2026-10-05）

1. **单词：现有 ECDICT 衍生词库的在线查询。** 55,081 个词条拆成 256 个分片，已上传公开仓库 `codex/online-lite`，通过 raw.githubusercontent.com 读取。单片最大约 60 KB，保留音标、词性、多义候选及拼写纠错；不下载整份释义词库，也不消耗 MyMemory 额度。纠错按需获取拼写索引；GitHub Pages 未启用。
2. **句子：MyMemory 官方公开 API。** 2026-10-05 从官方使用限制页核实：匿名免费额度 5,000 字符/日；主动提供可联系的有效邮箱（de 参数）可获 50,000 字符/日。邮箱不自动收集或虚构。免费不是无限量；限额、断网、超时须保留英文并明确提示，不自动切到付费服务。
3. **朗读：edge-tts 接入 Edge 在线语音。** 已实测美式 Aria 女声生成 MP3 并通过 Windows 原生音频组件播放；提供 Guy 男声、0.8 倍慢速和取消播放。英式设置对应 Sonia/Ryan 在线音色。维护者说明无须 API 密钥，但这是第三方库对 Edge 服务的接入，不属于 Azure 官方开发者 API 的免费额度保障；不承诺长期可用或与 Kokoro 音色相同。
4. **可选官方接口：Azure F0。** Translator 当前公开定价为每月 200 万字符免费；Speech F0 神经语音为每月 50 万字符免费。需要用户注册并配置资源密钥；仅作为备选，不启用付费层，不把开发者密钥嵌入公开程序。

## 已完成的服务探测

- MyMemory 英文到简体中文 API 返回 HTTP/业务状态 200，quotaFinished=false。
- `I sat on the bank.` → `我坐在岸边。`。
- `bank` → `银行`，其返回匹配中没有可用的“河岸”。因此它不能单独替代单词多义词典。
- 匹配列表还可能包含仅部分相似的原文，不能直接把这些译文加入中文候选；只保留对应当前完整原文的有效结果。句子不强行凑多个候选。
- 此次探测只是连通性与少量样例，不能作为全面翻译质量验收。

## 体积和交互建议（目标，尚非测量结果）

- 不随包带 Qwen、Kokoro、CUDA 和科学计算环境；尽量使用 Windows 自带网络与音频能力。
- 初步目标：安装包在几十 MB 内，程序与受限缓存合计控制在约 100 MB 内。最终以新实现的构建与安装实测为准。
- 语音磁盘缓存上限 20 MiB，超限移除旧音频；单词释义仅在内存中保留最多 16 个分片，拼写索引按需读取。设置中的清除缓存入口尚待补充。
- 单词输入停顿 450 毫秒后查询当前拼写，只展示精确匹配；没有前缀补全。句子按 Enter、语音手动触发时请求服务，不上传其他聊天内容。
- 网络结果在原文更改、切换模式、取消或焦点变化后失效，继续保持现有编辑和提交规则。
- 升级时还需要验证旧版卸载后的模型、备份与缓存清理；不能仅靠新包变小就声称现有电脑的占用已减少。

## 旧版保留与开发入口

- 旧版 `codex/sentence-mode` 保持在 `8758588`，`C:\Program Files\EType-0.2.0` 及原安装包保留。
- 新分支 `codex/online-lite`，独立服务端口 49182；不使用旧版离线服务 49181。
- 原生开发组件在 `build/online-lite/native`；`scripts/build-online-dev.ps1` 只编译开发与测试组件，不注册输入法、不生成安装包。新窗口暂时移除安装/卸载操作，设置和播放状态使用独立的 ETypeOnline 命名空间。
- 启动并显示开发预览：`scripts/start-online-dev.ps1 -ShowPreview`。首次开发环境需要 Python、`requirements-online.txt` 的轻量依赖，以及编译好的原生组件；正式独立运行环境和安装包尚未构建。
- 开发验证不等于已安装后的系统输入法验收。下一步仍需缓存清理入口、弱网/断网体验及后续用户要求的轻量安装包实测。
