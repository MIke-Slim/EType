# 在线精简版方案

## 用户已确认的目标（2026-10-05）

- 下载包与安装后的总占用都要小。
- 单词、句子翻译与朗读采用在线方案，翻译源选择免费服务。
- 保留既有单词多义候选、完整拼写与纠错、句子编辑、模式切换及确认键行为。
- 原 0.2.0 完整离线包的 GitHub Release 保持草稿，上传任务已停止。
- 按项目约定，先开发与测试；不因为讨论在线方案就生成新 EXE。

## 当前建议的服务分工（尚未完成接入或部署）

1. **单词：现有 ECDICT 衍生词库的在线查询。** 将少量词库分片放在公开仓库的免费静态托管中，查询后返回完整释义、音标、词性，保留 bank 的银行/河岸候选。静态查询不是句子机器翻译，不消耗 MyMemory 的句子翻译额度。GitHub Pages 是待验证的托管候选，尚未部署。
2. **句子：MyMemory 官方公开 API。** 2026-10-05 从官方使用限制页核实：匿名免费额度 5,000 字符/日；主动提供可联系的有效邮箱（de 参数）可获 50,000 字符/日。邮箱不自动收集或虚构。免费不是无限量；限额、断网、超时须保留英文并明确提示，不自动切到付费服务。
3. **朗读：评估 edge-tts 接入 Edge 在线语音。** 维护者说明无须 API 密钥，但这是第三方库对 Edge 服务的接入，不属于 Azure 官方开发者 API 的免费额度保障。仍需验证连接、音色、慢速、停止与重播；不能承诺长期可用或与 Kokoro 音色相同。
4. **可选官方接口：Azure F0。** Translator 当前公开定价为每月 200 万字符免费；Speech F0 神经语音为每月 50 万字符免费。需要用户注册并配置资源密钥；仅作为备选，不启用付费层，不把开发者密钥嵌入公开程序。

## 已完成的服务探测

- MyMemory 英文到简体中文 API 返回 HTTP/业务状态 200，quotaFinished=false。
- `I sat on the bank.` → `我坐在岸边。`。
- `bank` → `银行`，其返回匹配中没有可用的“河岸”。因此它不能单独替代单词多义词典。
- 匹配列表还可能包含仅部分相似的原文，不能直接把这些译文加入中文候选；只保留对应当前完整原文的有效结果。句子不强行凑多个候选。
- 此次探测只是连通性与少量样例，不能作为全面翻译质量验收。

## 体积和交互建议（目标，尚非测量结果）

- 不随包带 Qwen、Kokoro、CUDA 和科学计算环境；尽量使用 Windows 自带网络与音频能力。
- 初步目标：安装包在几十 MB 内，程序与受限缓存合计控制在约 100 MB 内。最终以新实现的构建与安装实测为准。
- 翻译/音频缓存设明确容量上限与清除入口，避免使用越久占用越大。
- 仅在完整单词触发查词、Enter 触发句子翻译或用户请求朗读时发送相关内容，不上传整段聊天或每次按键。
- 网络结果在原文更改、切换模式、取消或焦点变化后失效，继续保持现有编辑和提交规则。
- 升级时还需要验证旧版卸载后的模型、备份与缓存清理；不能仅靠新包变小就声称现有电脑的占用已减少。
