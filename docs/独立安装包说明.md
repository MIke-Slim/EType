# EType 0.2.0 单词与句子版

适用 Windows 10/11 x64。安装包内含输入法、离线词库、Qwen3-4B 句子模型、
Kokoro 美式自然语音及运行环境。安装后不依赖 Python、开发工具或本项目源码目录，
使用时无需下载模型或联网。模型和运行环境较大，请预留至少 8 GB 磁盘空间。

安装向导允许自行选择本机安装路径。安装需要管理员权限。
旧安装或开发试用配置尚在注册时，请先卸载旧配置，再安装本版，避免重复输入法。
已打开的软件需要完全退出并重新打开，才会加载新版输入法。

选择 Windows 输入法菜单中的「EType 单词与句子」。
Ctrl+Shift+空格切换模式：

- 单词：完整拼写，数字键或空格选中文；Enter 输出英文。
- 句子：连续输入英文，Enter 开始翻译；候选出现后 Enter 确认当前中文。
  Ctrl+Enter 随时输出英文原句。上下键选择候选，数字键或空格也能确认。

首次翻译或自然语音会自动启动隐藏的本地模型服务，需要等待模型加载。
支持的 NVIDIA 显卡可加速；没有可用显卡时使用 CPU，翻译可能较慢。
自然语音支持美式女声、男声和慢速；英式发音需要 Windows 对应音源。
译文由本地模型生成，仍可能发生误译。已知评测问题见随包的句子评测报告。

服务仅监听 127.0.0.1。缓存和日志存于 `%LOCALAPPDATA%\EType\local-ai`，
不会写入安装目录。设置与音频缓存保留在用户目录。

卸载前请切换到其他输入法，关闭使用 EType 的程序。若本地服务已启动，打开
http://127.0.0.1:49181/ 点击关闭服务，随后从 Windows「已安装的应用」卸载。
卸载器仅删除安装包管理的文件，保留用户后来添加的文件和用户目录中的偏好设置。

本安装包未使用商业代码签名证书。发布校验文件记录 SHA-256 和实际测试范围。
