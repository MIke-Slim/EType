EType 单词与句子 · 0.2.0 独立安装版

启动与模式切换
1. 运行 EType-0.2.0-Setup.exe，可在向导中自主选择安装路径。
   本版内置词库、句子翻译模型、自然语音及运行环境，不需要安装 Python 或开发工具。
2. 在要输入的窗口按 Win+空格，选择“EType 单词与句子”。
3. Ctrl+Shift+空格在单词模式和句子模式之间来回切换。
   两种模式属于同一个输入法；切换时有提示，候选窗左上角显示当前模式。
   未确认的内容在切换时保留为英文，不自动选中文；设置记住最后选择的模式。
4. 单词模式空格选中文；句子模式空格用于英文单词之间的分隔。
5. 安装目录是运行位置，使用后不要直接移动或删除。
   首次翻译或美式发音会自动启动本地服务，可能需要等待模型加载。
   设置入口在开始菜单“EType 单词与句子”，可选创建桌面快捷方式。
   旧版或开发试用配置尚在注册时，需先卸载旧配置，再安装本版。

直接试用
设置窗口可通过“直接试用（无需安装）”体验。
免安装模式只在本软件自己的试用文本框生效。

单词输入
完整输入 bank 后，候选为“银行／河岸”。空格选当前项，数字 1—5
选择当前页候选，方向键移动，Page Up / Page Down 翻页。
回车输出英文原文，Esc 取消本次输入，Backspace 删除字母。
单独按 Shift 在英文转中文和英文直输之间切换。

句子输入
Ctrl+Shift+空格切到句子模式，输入完整英文句子，再按 Enter 请求翻译。
例如输入 I sat on the bank.，翻译候选可为“我坐在河岸上。”。
候选出现后再次按 Enter 确认当前中文，也可用 1—3 或方向键、空格选择。
Ctrl+Enter 直接输出英文原句，包括有中文候选或正在等待翻译时；Esc 取消。
等待期间重复 Enter 不会重复请求或输出英文；翻译失败后按 Enter 可重试。
左右键、Home/End 编辑英文原句，Shift 选中，Ctrl+左右逐词移动。
F2 展开或收起长译文；可以滚动查看全文，也可以点击“翻译 / 重试”。
每次最多 500 个 ASCII 字符。本地模型仍可能翻译错误，需要自己选择和检查。

纠错
输入 aple 时不自动补全。按空格后显示可能的正确拼写；选择 apple 后，
再选择中文才输出“苹果”。未找到单词时仍可回车输出英文。
app 是独立有效单词，只提供“应用程序”，不会预测成 apple。

词形
支持 books、went、running 等词形，显示原形和变化类型。
中文候选保持固定顺序，不根据使用历史变化。
候选只输出中文，音标、词性和说明不会进入正文。

发音和设置
点击候选窗口的“发音”播放当前单词，默认美式。
设置窗口可调整字号、音量、发音口音和中英文标点。
美式发音使用内置 Kokoro 自然语音，支持女声、男声、慢速、重播与停止。
单词和句子共用音色。英式发音使用 Windows 英式音源；缺少对应音源会提示。
部分词库音标为英式，发音口音由设置决定。

其他规则
查词和纠错不联网。候选最多五项一页，后续候选可以翻页。
有候选时标点先确认当前中文；未找到单词时保留英文再输出标点。
英文直输模式使用英文标点，适合网址、邮箱和代码。
切换窗口时未确认的文字保留为英文，不自动选择中文。
粘贴不会自动翻译。密码框和特殊输入区域遵循系统及应用规则。

范围
本版为原生 Windows 桌面 TSF 输入法，提供 x64 和 x86 组件。
免安装试用仅作用于本软件的文本框，使用同一个输入法 DLL。
试用成功不代表已完成系统安装及其他软件的兼容性验证。
不同软件、现代应用、受保护区域的兼容性需要分别验证。
本版包含单词与句子输入；不包含中文反查、账户、打卡、学习统计和云同步。

卸载
可在设置窗口点击“卸载输入法”，或在 Windows“已安装的应用”中卸载。
先关闭使用 EType 的程序；若本地服务已启动，在 http://127.0.0.1:49181/ 点击关闭服务。
卸载器取消注册并删除本包管理的文件，保留个人偏好和用户后来保存的文件。
如果文件被占用，先切换到其他输入法、关闭相关软件，再次卸载。

用户设置：%LOCALAPPDATA%\EType\settings.ini
模型服务缓存与日志：%LOCALAPPDATA%\EType\local-ai
安装目录：以安装向导中用户自主选择的路径为准。
本轮完成组件与隔离安装流程测试；正式系统注册和 Word、微信等外部软件兼容需安装后验收。
