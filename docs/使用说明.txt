EType 英文词汇输入法 · 第一版

安装
1. 将整个 EType 文件夹解压到本地，运行 EType.exe。
   不安装时可以点击“直接试用（无需安装）”，在本窗口体验词汇输入。
2. 点击“安装系统输入法”，按 Windows 的管理员提示完成安装。
3. 从系统输入法列表选择“EType 英文词汇输入法”。
4. 已打开的软件可能需要重新打开。原有输入法及默认输入法不变。

输入
完整输入 bank 后，候选为“银行／河岸”。空格选当前项，数字 1—5
选择当前页候选，方向键移动，Page Up / Page Down 翻页。
回车输出英文原文，Esc 取消本次输入，Backspace 删除字母。
单独按 Shift 在英文转中文和英文直输之间切换。

纠错
输入 aple 时不自动补全。按空格后显示可能的正确拼写；选择 apple 后，
再选择中文才输出“苹果”。未找到单词时仍可回车输出英文。
app 是独立有效单词，只提供“应用程序”，不会预测成 apple。

词形
支持 books、went、running 等词形，显示原形和变化类型。
中文候选保持固定顺序，不根据使用历史变化。
候选只输出中文，音标、词性和说明不会进入正文。

发音和设置
点击候选窗口的“发音”播放当前单词，默认美式。
设置窗口可调整字号、音量、发音口音和中英文标点。
发音使用本机 SAPI 离线英语音源；缺少对应音源会提示。
部分词库音标为英式，发音口音由设置决定。

其他规则
查词和纠错不联网。候选最多五项一页，后续候选可以翻页。
有候选时标点先确认当前中文；未找到单词时保留英文再输出标点。
英文直输模式使用英文标点，适合网址、邮箱和代码。
切换窗口时未确认的文字保留为英文，不自动选择中文。
粘贴不会自动翻译。密码框和特殊输入区域遵循系统及应用规则。

范围
本版为原生 Windows 桌面 TSF 输入法，提供 x64 和 x86 组件。
免安装试用仅作用于本软件的文本框，使用同一个输入法 DLL。
试用成功不代表已完成系统安装及其他软件的兼容性验证。
不同软件、现代应用、受保护区域的兼容性需要分别验证。
第一版不包含中文反查、短语/句子翻译、账户、打卡、学习统计和云同步。

卸载
在设置窗口点击“卸载输入法”。个人偏好保留。
如果文件被占用，先切换到其他输入法、关闭相关软件，再次卸载。

用户设置：%LOCALAPPDATA%\EType\settings.ini
安装目录：%ProgramFiles%\EType
