# 原生单词与句子开发版

本版本保留单词版，增加本地句子翻译和已认可的美式自然语音。仅供工作区开发试用，没有重新安装系统输入法或生成安装包。

## 启动

资源已经在本机准备好时，在仓库根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start-development.ps1
```

脚本启动本机 AI worker，再打开 `build/EType/EType.exe` 开发窗口。点击“直接试用（无需安装）”，在框内输入。首次服务启动需要加载模型；若服务关闭，可重新执行启动脚本。

## 输入与播放

- 单词模式沿用完整拼写、释义选择及两次确认的拼写纠错。
- Ctrl+Shift+空格切换单词/句子，也可点击候选窗左上角模式名。切换时已有原句保留为英文。
- 句子模式中空格分词，数字和 ASCII 标点保持原样，最多 500 字符。输入后按 Enter 翻译；候选出现后再次 Enter 确认当前中文，也可用 1–3，或上下键选择后按空格。
- 左右键移动原句光标，Home/End 跳到句首/句尾；Shift 配合这些键选中原文，输入可替换选区。Ctrl+左右键逐词移动，Ctrl+Backspace/Delete 逐词删除；也可在试用框中用鼠标定位、选中后修改。
- 移动光标开始编辑时收起已有译文，修改原句会使旧结果失效；再次 Enter 或点击候选窗“翻译 / 重试”请求新译文。
- 长译文按 F2 或点击候选窗底栏展开全文，鼠标滚轮或滚动条查看，再按 F2 收起。展开本身不会提交中文；上下键仍切换候选，空格确认。
- Ctrl+Enter 输出英文原句，Esc 删除正在组合的原句。等待期间 Enter 不重复请求、不输出原文；翻译失败保留原句，Enter 可重试。修改原句或输出英文会使旧结果失效。
- 设置中的“播放英文 / 重播”优先播放试用框选中的 ASCII 英文，否则播放框内英文；已提交中文时重播本次窗口记住的上一句英文，没有原句记录时使用 apple 示例。候选窗“发音”播放正在输入的原句。
- 美式使用本地 Kokoro，可选女声/男声和正常/慢速，停止按钮取消播放。音量仅影响本软件。英式使用 Windows 英式音源，需用户电脑已安装。
- 服务只监听本机 127.0.0.1。开发页面 <http://127.0.0.1:49181/> 的关闭按钮会停止它启动的模型进程。

播放状态区分准备、播放、完成、停止中、已停止和失败；候选窗播放期间的“发音”按钮变为“停止”。重播会取消上一轮播放，旧进程的结束不会覆盖新播放状态。生成期间停止会取消客户端请求并及时结束播放进程；本地模型已开始的生成可能继续完成，但不会随后出声。缓存重播不等待其他句子的生成。首次未缓存语音需要加载音源，长句准备时间可能超过 10 秒。

候选默认紧凑显示，可展开查看完整内容；提交内容保持完整。模型复核和少量语义规则不能保证译文正确，仍需确认语义。开发样本及未解决问题见 `句子评测报告.md`。

## 开发验证

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -SkipDictionary -ToolchainPath "C:\path\to\llvm-mingw"
build/tsf-tests.exe build/EType/x64/EType.dll --local-ai
build/tsf-tests-x86.exe build/EType/x86/EType.dll --local-ai
build/EType/EType.exe --sentence-selftest build/sentence-ui-selftest.json
build/EType/EType.exe --natural-speech-test build/natural-native.wav
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/test-local-ai.ps1 -ToolchainPath "C:\path\to\llvm-mingw"
```

常规构建包含核心、词库、两个架构 TSF 及原生试用文本框回归。`--local-ai` 和 `--sentence-selftest` 需要已启动本机模型，验证真实 TSF 原句替换、中文候选提交及过期结果保护；这些组件测试会直接转发按键，不能代替安装后外部应用兼容性验收。

测试设置写入独立文件，不覆盖用户偏好；模型、运行环境和生成证据都位于 Git 忽略的 `build/`。

2026-10-04 本机验证结果：核心 88 项；词库 7 组；两个架构常规 TSF 各 158 项、包含真实本地翻译的 TSF 各 165 项；Python 适配器 11 项；原生音频桥 11 项；跨进程语音状态 15 项。原生试用框的单词、真实翻译、光标编辑、Shift 选区、鼠标替换和过期结果检查通过。展开全文、滚动到底、收起和重试按钮的原生窗口检查通过。播放与生成请求取消均在测试规定的 1.5 秒内结束播放进程；不代表本地模型计算同时终止。

常规构建与真实模型组件测试用的键盘状态由测试进程注入。宿主同步可能处理桌面按键消息，因此测试在同步后、调用每个按键接口前设置状态，并在调用后恢复，避免测试期间的真实 Ctrl 键干扰。此调整只影响自测入口。

对应证据：`build/core-test-results.txt`、`build/tsf-test-results*.txt`、`build/tsf-local-test-results*.txt`、`build/local-bridge-test-results.txt`、`build/speech-state-test-results.txt`、`build/ui-selftest.json`、`build/sentence-ui-selftest.json.sentences.json`、`build/native-ui-preview/interaction.json`。界面实图位于 `build/native-ui-preview/`；其中句子和长候选图片使用固定测试文本检查布局，真实模型译文上屏另由句子测试报告证明。
