EType third-party notice

Offline English-Chinese data is derived from skywind3000/ECDICT.
https://github.com/skywind3000/ECDICT
The upstream MIT license is included in licenses/ECDICT-LICENSE.
See data/manifest.json for the exact source and output SHA-256 hashes.
Upstream entries are filtered to single words, short Chinese candidates and
common/exam vocabulary. Small everyday candidate overrides are in the source
project at data/overrides.json. Inflections derive from upstream exchange fields.
Source phonetics are predominantly British and are not automatically relabeled
as American. Spoken accent is selected independently from installed local voices.

Built with LLVM MinGW. Statically linked runtime notices are included in
licenses/LLVM-LICENSE.txt and licenses/COPYING*. The development toolchain
itself is not needed to run EType.
https://github.com/mstorsjo/llvm-mingw

The EXE installer is built with official Inno Setup 6.7.3 by Jordan Russell
and Martijn Laan. Its license is included in licenses/InnoSetup-LICENSE.txt.
https://jrsoftware.org/isinfo.php
The Simplified Chinese installer translation is sourced from the official
issrc Languages directory; original translator notices remain in the source.
https://github.com/jrsoftware/issrc/tree/main/Files/Languages
