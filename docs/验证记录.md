## 验证边界

TSF 集成测试使用临时进程内配置，由 Windows 创建并激活 DLL，随后调用
输入服务的按键接口。试用框使用同一 DLL 和实际 TSF 文字上下文，由应用
自行转交按键。两者均不能证明系统已全局安装，或其他软件已正确转交按键。
后台组件自测不抢占前台，也不关联失活窗口的系统焦点；它主动注入激活通知，
显式请求组件焦点切换并验证恢复后的文字提交。报告如实记录请求结果与系统观察，
后台 GetFocus 不等于试用文档不作为前台获焦成功的证据。

安装测试使用同源但单独编译的验证安装器，验证文件和私有安装记录的真实生命周期，
不注册全局 TSF 服务。本轮未执行生产安装器的管理员全局注册及全局卸载。
Word、微信、浏览器和现代应用的兼容性仍需安装后分别验收。
密码框包含绕过处理，但尚未在各类宿主中逐项验证。

安装向导保留目录选择页，默认 Program Files\\EType，允许自主浏览选择本地普通空目录。
本版更新或更换路径需要先卸载；偏好文件位于用户 LocalAppData，卸载会保留。
候选语义未逐条人工校对。选定的快捷候选条仍是设计预览，尚未替换原生窗口版式。

此前已检测到本机美式英语音源并合成非静音 WAV，未检测到英式音源；
本轮未重新验收实际扬声器播放。词库音标部分为英式，不随播放口音改写。
