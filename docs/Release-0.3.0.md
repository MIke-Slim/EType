# EType 0.3.0 在线轻量版

面向 Windows 10/11 x64 的英文学习输入法。输入完整英文单词，选择中文释义；也能输入完整英文句子，翻译后确认中文。

- 单词保留音标、词性、多义候选和拼写纠错，例如 bank 的“银行”和“河岸”。词库按需联网获取，不内置整份离线模型。
- Ctrl+Shift+空格切换单词/句子。句子模式 Enter 获取中文，再按 Enter 确认；Ctrl+Enter 输出原始英文。
- 在线英文朗读支持美式/英式、女声/男声、正常/慢速、重播与停止。
- 采用 MyMemory 免费句子翻译；匿名额度 5,000 字符/日，额度用完或连接失败保留英文，不转为付费服务。翻译结果仍需用户确认。
- 单词词库固定到公开仓库的版本；Edge 在线语音通过第三方接口接入，服务可用性会影响朗读。
- 安装器允许自主选择安装路径，提供 Windows 标准卸载。旧离线版与在线测试版使用不同输入法身份，可保留并切换。
- 不内置 Qwen、Kokoro、CUDA 或科学计算环境；语音缓存最多 20 MiB。

安装后按 Win+空格选择“EType 在线版”。已打开的软件可能需要重新打开才能刷新输入法列表。

附件包括 EXE 安装包、SHA-256 校验文件和测试记录。安装包签名状态：未签名。
