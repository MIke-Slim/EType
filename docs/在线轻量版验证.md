- 原生预览使用同一 TSF 输入服务，但测试直接向组件传递键盘事件，没有注册新系统输入法；外部聊天软件中的新版系统输入法尚未安装验收。
- 真正联网样例不等于全面的词库、翻译质量及弱网验收。网络、GitHub 可访问性、服务免费额度与 Edge 非官方语音接口仍会影响使用。
- 没有完整在线独立运行环境或安装包；原生文件大小不能代表最终下载包和安装总占用。开发 Python 环境也不等于正式运行环境。

本轮开发服务使用 49182，旧版 49181 不变。语音缓存限制 20 MiB；释义按需读取，最多缓存 16 个分片到内存，不携带离线翻译/语音模型或 CUDA。
