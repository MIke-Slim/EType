# EType UI 设计决策

2026-10-04，用户选定第一种方案：**快捷候选条**。

## 候选窗口

- 第一行显示完整英文单词、词库音标和词形信息，右侧放手动发音与设置入口。
- 第二行横向显示编号、中文释义和词性；当前候选以淡蓝底色突出。
- 底部用轻量提示显示空格选词、回车保留英文和 Esc 取消。
- 设置入口展开附属的快速设置面板，提供字号、发音口音、音量与默认标点。
- 拼写纠错先展示英文建议，确认拼写后再展示中文候选，保留两次确认。
- 以键盘操作为主，保持窗口紧凑，靠近正在输入的位置。

## 视觉方向

使用 Windows 简洁风格，浅色表面、细边框和轻微阴影。主要强调色为蓝色
`#245FB5`，浅色候选高亮为 `#EAF1FD`。深色外观采用对应的深色表面与高对比文字。

2026-10-04，用户提供并确定蓝色 Logo。保留原始透明 PNG 于 `assets/etype-logo.png`，
Windows 多尺寸图标于 `assets/etype.ico`，不重新生成或修改图案。
Logo 接入设置窗口、程序/快捷方式图标、两种架构 DLL 的输入法注册图标及安装器。
