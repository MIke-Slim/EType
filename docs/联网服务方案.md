# 联网翻译与语音方案（讨论稿）

核查日期：2026-10-04。此文为方案建议，不代表服务已接入、音色已试听或费用已获授权。

## 服务比较

| 方案 | 用途与取舍 | 当前判断 |
| --- | --- | --- |
| 阿里云百炼文本模型 + Qwen3-TTS | 同一服务平台提供中文候选生成和英文语音；使用支持结构化输出的文本模型生成候选数组，客户端校验数量、长度、重复项 | 建议优先验证；接口能力不等于翻译质量已通过测试 |
| 文本模型 + Azure Speech | 翻译候选生成与语音分开配置；Azure 提供神经语音，支持通过 SSML 控制朗读节奏和语速 | 作为语音试听对照；需要另一个服务资源与凭据 |
| Windows 本地语音 | 沿用已有离线方案 | 可作为断网时的显式回退；无法据此保证改善用户反馈的生硬听感 |

Qwen-MT 是专用翻译模型。官方示例展示一条译文；当前未找到可直接返回几种不同中文表达的合同，因此不能把响应中 `choices` 字段的存在当成已支持多候选。首轮建议用通用文本模型一次生成 1–3 条忠于原意的中文表达，不强行凑满三条；Qwen-MT 可用于后续质量对照。

## 首轮待验证组合

- 中文候选：百炼 `qwen-flash`，非思考模式与结构化输出；选择模型仍需与实际句子评测结果一致。
- 英文语音：`qwen3-tts-flash`，先试听美式女声 `Jennifer` 与美式男声 `Aiden`。官方音色表确认二者适用于该模型。尚未试听，不承诺实际自然程度。
- 慢速播放：先核查所选模型的参数或指令支持，再测试效果；普通 Flash 与 Instruct Flash 的能力不能混用。必要时更换可控制语速的模型，或使用保持音高的本地播放变速。
- 朗读整句英文，让服务处理连读、重音和停顿；不要逐词拼接句子音频。

## 可核对的费用

以下为官方文档的华北2（北京）价格，不含活动额度，正式接入前需按账户地域再次确认。

- `qwen-flash`：单次输入不超过 128K Token 时，每百万输入 Token 0.15 元，每百万输出 Token 1.5 元。Token 数包括指令及生成的候选，不能直接等同于句子数量。
- `qwen3-tts-flash`：每万计费字符 0.8 元，输出不计费。英文字母、空格、数字、标点各按一个字符计算。
- 仅作算术示例：每天首次合成 5,000 个英文计费字符，30 天共 150,000 字符，语音原价为 12 元；不包含候选生成费用，也不代表实际月用量。
- 缓存命中并在本地重播时不发起新的语音合成请求；清除缓存或改变模型、音色、朗读参数可能需要重新请求。
- Azure 本次仅核查功能，没有取得适用于用户账户地域、币种、套餐的确定价格，不填写猜测数字。

## 应用中的操作建议

1. 单词模式保留当前本地查词、纠错和多义候选。
2. 句子模式空格分词，完成输入后主动翻译。2026-10-04 用户已确认：`Enter` 翻译并确认中文，`Ctrl+Enter` 输出英文原句。
3. 中文候选按自然程度排序；必要时标明不同理解，避免把不同意思伪装成同义表达。生成失败保留英文，提供重试。
4. 单词与句子共用音色设置、手动播放、停止、重播与慢速播放入口。
5. 点击翻译或播放才发送当前英文内容，不上传键盘逐字输入记录、其他应用文档或周边文本。网络与音频任务放在独立工作进程，避免阻塞宿主应用。
6. 凭据通过本机设置入口配置，使用 Windows 凭据存储或 DPAPI 保护；不写进源码、仓库或输入法 DLL。

## 接入前需要完成的验证

- 使用相同测试文本比较两组美式音色：单词 `bank`、`through`、`comfortable`；句子 `I went to the bank to deposit some money.` 与 `We sat on the bank and watched the river.`。
- 翻译测试覆盖多义词、否定、数字、缩写、专有名词；候选不得增加原句没有的信息。
- 记录真实请求等待时间、失败情况和服务返回的计费用量；尚未进行线上 API 调用。
- 服务账户、凭据与付费用量安排尚未确定。当前允许联网，没有据此购买或充值服务。
