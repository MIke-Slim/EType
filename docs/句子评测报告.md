# 句子翻译开发回归评测

2026-10-04，在本机 Qwen3-4B-Q4_K_M 上运行 34 条预先编写的英文句子，逐句检查否定、时态、多义词、人物角色、数字、日期、文件名及长句条件。参考中文仅用于说明含义，不要求逐字匹配。完整输入、输出、模型复核和开发助手逐句复核结论见 `句子评测结果.json`；样本定义见 `data/sentence-evaluation.json`。

本轮用这些样本调整过提示词和规则，因此是开发回归检查，不是独立盲测、用户验收或通用准确率测试。

## 已修正的具体问题

| 原问题 | 当前处理 |
| --- | --- |
| 将按件数的 sales 译为“销售额” | 检查数量与金额区别，重新生成并再次复核；该例现在译为“销量增加了15%，从200件增至230件” |
| hardly ever 夹带未翻译的 never | 对未译出的频率词要求整体重译；该例现在译为“我几乎不喝咖啡” |
| 过去反事实被译成普通条件 | 提示保留当时未实现的假设，加入窄范围检查；本例保留“早就……了” |
| send report/results 擅加邮寄渠道 | 重译为“发送/发给”，两个长句的时间、数量、角色及否定保留 |
| 帮忙的对象被省略 | 检查少数常见帮助对象；无法保留对象时拒绝候选，英文原文可继续编辑 |

每次请求最多两次生成，每次均重新进行模型复核。没有直接替换成预写样本答案，也没有返回未经复核的失败草稿。开发报告保留被拒绝的原始输出，便于后续定位问题。

## 仍然存在的限制

同一个小模型进行翻译和复核，可能同时犯错。少量规则只覆盖已发现的部分问题，也可能拒绝可接受的表达；通过复核不等于语义必然正确。“住了三年”保留时长，但持续至今不够明确；称谓、目的与已完成行为等仍需要更广泛、独立的测试。

当前支持单句或一段不超过 500 个 ASCII 英文字符的输入。暂未完成安装后记事本、Word 和浏览器等外部应用的兼容性验收。本轮没有生成安装包。

重跑原始模型输出：先启动本地服务，再运行 `build/local-ai/venv/Scripts/python.exe scripts/evaluate_sentences.py --label new-run`。输出位于 `build/local-ai/evaluation-new-run.json`，默认复核状态为 pending，需要重新逐句检查，不能沿用本报告结论。
