# EType 第一版需求基线

本文件记录 2026-10-03 与用户确认的功能。目标为 Windows 电脑输入法，
通过日常中文输入练习英文拼写和词汇；句子功能留到以后。

## 输入

只有完整英文单词才能提供中文候选；不按拼音转换，不预测部分单词。
`app` 是有效单词，可输出它自己的释义，但不能补全成 `apple`。
支持一词多义，如 `bank` 的“银行／河岸”，顺序固定，不随个人使用变化。
支持复数、过去式等真实词形，候选显示原形及变化类型。
候选使用简短中文词语，音标、词性和说明不进入正文。
普通单词查词不区分大小写，英文原文保留输入大小写。

## 纠错与英文

输入过程中不做预测。未匹配时按空格才提供纠错建议，最多五项。
确认正确英文之后，再选择中文才能上屏；不能直接把纠错建议变成中文。
有效单词不自动改为其他单词。没有匹配词时提示“未找到该单词”，
避免直接认定拼错。回车始终允许输出当前英文原文。
不提供中文反查英文功能。

## 操作

空格选择当前中文候选；数字 1—5 选择当前页；方向键移动；
Page Up / Page Down 翻页；Backspace 删除字母；Esc 取消本次输入。
单独按 Shift 切换英文转中文和英文直输。英文直输适合网址、邮箱和代码。
无候选时数字正常输入。有候选时数字用于选词。
默认中文标点，可切换英文标点；英文直输模式默认英文标点。
有中文候选时标点先确认当前中文再上屏标点；无候选时保留英文再上屏标点。
标点不能自动确认纠错建议。切换窗口时未确认内容保留为英文。
粘贴内容不自动翻译。其他输入法和特殊输入区域遵循系统/软件原有规则。

## 候选、发音、设置

候选窗口显示英文、音标、词性，以及必要的原形与词形提示。
发音默认美式，保留英式切换；手动点击，不自动朗读。
本地查词、释义和纠错必须离线运行。发音优先使用本地离线音源，
缺少音源时提示，不阻止文字输入。可靠音标缺失时不猜测音标。
设置包含候选字号、发音口音和音量、中英文标点，显示词库版本。

## 词库、安装、范围

初始覆盖日常常用英语与常见词形，不限定单一考试词表，可后续扩充。
第一版不提供用户手动新增词条、不做短语/句子翻译、打卡、积分、学习统计、
账户登录或云同步。
交付实际 Windows 系统输入法组件、安装/卸载方式及中文说明。
系统输入法安装需要 Windows 管理员授权，不能把本窗口试用称为已安装。
兼容性以本机为起点，在常用软件里逐项验证。
